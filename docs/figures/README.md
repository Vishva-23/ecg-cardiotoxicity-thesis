# Figures

Figures referenced by the documents in [`docs/`](../). The full `outputs/` folder
is git-ignored (it is regenerated by the notebooks); these are the committed ones.

> **Landmark windows corrected (see notebook cells `nb02-41-gallery` / `nb04-06-overlay`).**
> Figures now mark the waves where they physically occur in mouse ECG:
> **P → Q → R → S (+5 ms) → J (+8–10 ms) → T (+20 ms, *inverted*) → repolarisation
> complete (~+31–40 ms)**. Earlier figures used windows calibrated too late: what was
> labelled *S* (8–32 ms) is actually the inverted **T wave**, and the *T* search
> (40–80 ms) landed on the **next beat's P wave** at mouse heart rates. Verified
> against the averaged-beat morphology of all ten gallery animals. Note this differs
> from the windows still used inside `_measure_one`, which are pending a decision on
> the correct convention — so `s_wave_amplitude_mv`, `t_wave_amplitude_mv`,
> `rt_interval_ms` and `j_wave_amplitude_mv` in the feature table are affected.
> `qt_ms` / `qtc_ms` are **not** affected (that search is RR-bounded).
